# 双 DJI ACTION4 RGB 视频位姿估计代码详解

本文说明 `pose3d/` 目录如何实现：

```text
RGB 视频帧 -> YOLO 检测 -> 两个 ROI -> 共享角点网络 -> 8 通道 Heatmap
-> 提取二维角点 -> solvePnPRansac -> EMA 时序平滑
```

## 文件结构

- `boxdreamer_single.py`：全图数据集、ROI 角点网络和 Heatmap 损失。
- `roi_pipeline.py`：单实例 ROI 数据集、峰值提取、PnP、跟踪和视频流水线。
- `train_heatmap.py`：角点网络训练入口。
- `detect_image.py`：只运行 YOLO 图像检测。
- `run_video.py`：视频端到端推理。

## 数据读取

`annotations.json` 为每张图像提供 RGB 路径、Heatmap 路径以及两个实例的 `corners_2d`。`PoseHeatmapDataset` 读取整图和 8 通道 `.npz` 标签，并把 RGB 统一缩放到 `240x180`、转为 `CHW` Tensor、执行 ImageNet 归一化。

`RoiPoseDataset` 从同一份标注派生单实例样本。它读取某个实例的 8 个角点，计算包围框并外扩 15%，裁剪 ROI 后缩放到 `240x180`，再把角点转换到 ROI 坐标，在每个角点处绘制高斯 Heatmap。1475 张双目标图像因此产生约 2950 个单实例样本，左右实例使用同一个网络。

## BoxDreamerSingle 网络

网络保留论文 3.2 的主要结构，但移除了当前任务不需要的多参考图像分支。

输入尺寸为 `180x240`，patch size 为 15，因此得到 `12x16=192` 个图像 token。`Conv2d(3, 256, 15, 15)` 完成 Patch Embedding。参考 Heatmap（如果传入）通过 `unfold` 分块，再由线性层映射到 256 维并加到图像 token 上；默认训练使用可学习 Query Token。

Transformer 默认配置为 6 层、隐藏维度 256、8 个注意力头，适合本地设备。每个 token 经线性层还原为 `8x15x15`，再由 `F.fold` 拼回 `8x180x240`，最后使用 Sigmoid 输出 Heatmap。

论文的粗粒度监督在代码中对应：

```python
F.smooth_l1_loss(pred_heatmap, target_heatmap)
```

## Heatmap 峰值

`extract_peaks()` 对每个通道找最大响应。如果峰值低于阈值，则标记为无效；否则使用最大点周围 `3x3` 区域的加权质心，得到比直接 `argmax` 更平滑的二维位置。

## YOLO 检测和 ROI

`VideoPosePipeline._detect()` 调用 Ultralytics YOLO，取得 `xyxy` 检测框和置信度，按置信度排序后保留最高的两个框。每个框外扩 15% 后独立裁剪，两个 ROI 依次输入同一个 `BoxDreamerSingle` 实例。

ROI 坐标映射回原图的公式为：

```text
x_full = x_roi * crop_width / 240 + crop_x1
y_full = y_roi * crop_height / 180 + crop_y1
```

因此 PnP 使用原始图像坐标和原始相机内参。

## PnP

程序从 `models/models_info.json` 读取模型尺寸，构造以物体中心为原点的 8 个三维包围盒角点。预测二维角点与三维角点按固定通道顺序配对，并调用：

```python
cv2.solvePnPRansac(object_points, image_points, K, dist)
```

输出 `rvec`（旋转向量）和 `tvec`（平移向量）。模型尺寸当前以毫米为单位，所以平移结果也是毫米。合成 `camera.json` 可用于初步测试，真实视频应使用 ACTION4 的实际标定内参。

## 视频跟踪和平滑

`EMATracker` 先按检测框 x 坐标排序，再用位置距离判断是否与上一帧对应。对应成功后，对旋转向量和平移向量进行指数移动平均：

```text
new = alpha * current + (1-alpha) * previous
```

默认 `alpha=0.65`。当前实现是稳定视频流程的初版；目标交叉或长时间遮挡时可升级为 Kalman Filter、Hungarian matching，并将旋转向量平均改为四元数 SLERP。

## 训练

训练单实例 ROI 网络：

```bash
conda run -n pose3d python -m pose3d.train_heatmap \
  --root TripoSR/dataset/demo-bin-picking \
  --roi --epochs 30 --batch-size 8 --workers 0 \
  --device auto --out checkpoints/boxdreamer_roi.pt
```

不加 `--roi` 时使用整图双峰 Heatmap baseline。

## 单张图像检测

先安装检测依赖：

```bash
conda run -n pose3d pip install ultralytics
```

然后运行：

```bash
conda run -n pose3d python -m pose3d.detect_image \
  --image frames/frame_00000s.jpg \
  --weights checkpoints/dji_action4_yolo.pt \
  --out outputs/detection_frame_00000s.jpg
```

脚本只绘制置信度最高的两个检测框，适合独立检查检测质量。

## 视频推理

```bash
conda run -n pose3d python -m pose3d.run_video \
  --video head_left_rgb_raw.mp4 \
  --detector checkpoints/dji_action4_yolo.pt \
  --corner-weights checkpoints/boxdreamer_roi.pt \
  --camera TripoSR/dataset/demo-bin-picking/camera.json \
  --out outputs/pose_result.mp4
```

## 当前限制

1. 项目中尚无训练完成的 YOLO 权重，需要先准备 `dji_action4_yolo.pt`。
2. 当前 Mac 环境没有 CUDA 或 MPS，将使用 CPU。
3. 当前是轻量版 Transformer，并非论文的 DINOv2-Base、12 层、768 维完整配置。
4. 两个目标严重交叉或长时间不可见时，当前简单跟踪器需要升级。
5. 真实相机内参会直接影响 PnP 位姿精度。
