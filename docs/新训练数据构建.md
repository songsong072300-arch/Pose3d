## 一键批量生成（推荐）

输出必须是新目录或空目录；脚本会在渲染前拒绝混入已有数据。
下面生成新的 2000 张、4 个 scene（每个 500 张），其中 1 个 scene 用于 val：

```powershell
& $py TripoSR/build_training_data.py --num-images 2000 `
  --frames-per-scene 500 --samples 32 --render-device auto `
  --output-split new_train_pbr_v1 --labels-dir new_corner_labels_v1 `
  --yolo-out checkpoints/yolo_new_train_pbr_v1 --seed 20261010
```

CPU 小批量使用 `--render-device cpu`；auto 使用 BlenderProc 自动选择的 GPU。
正式批量建议保留多个完整 scene，不能用 2 张样本的验证指标判断真实效果。

若仅想再次测试 2 张，在新目录运行：

```powershell
& $py TripoSR/build_training_data.py --num-images 2 --frames-per-scene 1 `
  --output-split new_train_pbr_smoke2 --labels-dir new_corner_labels_smoke2 `
  --yolo-out checkpoints/yolo_new_train_pbr_smoke2 --seed 20261011
```

## 分步指令（本次实际使用的参数）

以下渲染指令会追加新 scene；本次数据已存在，不要为了查看结果再次执行第一步。
如果需要完整重建，优先使用上面的新目录一键命令。

```powershell
# 1. RGB、深度、位姿和内参
& $bp run TripoSR/render_dataset.py 2 `
  --dataset-dir TripoSR/dataset/lm --output-split new_train_pbr `
  --frames-per-scene 1 --render-device cpu --samples 16 --seed 20261009

# 2. 8 个角点和热图，只读取 new_train_pbr
& $py TripoSR/generate_corner_heatmaps.py TripoSR/dataset/lm `
  --image-split new_train_pbr --output-root TripoSR/dataset/lm/new_corner_labels `
  --split-mode scene --val-scene-count 1

# 3. YOLO 导出；输出已有数据时会拒绝覆盖，需改用新的 --out
& $py -m pose3d.train.export_yolo_labels `
  --root TripoSR/dataset/lm --labels-dir new_corner_labels `
  --out checkpoints/yolo_new_train_pbr

# 4. 角点叠加预览
& $py TripoSR/visualize_corner_ground_truth.py TripoSR/dataset/lm `
  --labels-dir new_corner_labels --instance-crops
```

自定义 split 使用临时 BOP 写入目录，成功后将完整 scene 放到指定 split，
不会向旧 train_pbr 追加，也不会改写 lm/camera.json。若渲染失败，
`.render_staging_*` 会保留中间数据供排查。此次未开启 --bop-masks，
角点和 YOLO 导出不依赖分割 mask。
