# 角点网络执行流程

## 训练路径

```text
annotations.json + splits.json
  -> RoiCornerDataset
  -> 一帧两个实例拆为两个 ROI 样本
  -> 随机扰动裁剪框
  -> Letterbox 到 168x224
  -> 现场生成 8 个单峰 Heatmap
  -> DINOv2 四层中间特征
  -> 特征融合解码器
  -> 8x168x224 Heatmap
  -> Heatmap 损失 + 2.0 x 坐标损失
```

当前标注包含 1475 帧，每帧两个实例，因此 ROI 模式产生 2950 个样本。训练、验证和测试仍按原始帧划分，两个来自同一帧的 ROI 不会泄漏到不同集合。

## 推理路径

```text
RGB 图像或视频帧
  -> YOLO 取置信度最高的两个相机框
  -> 每个框外扩 15%
  -> 与训练相同的 Letterbox
  -> 共享 CornerHeatmapNet
  -> 每通道最大峰附近 3x3 加权质心
  -> 8 个 ROI 坐标
  -> Letterbox 逆变换
  -> 每个实例 8 个原图坐标
```

任务输出停在二维角点，不执行 PnP。

## 张量形状

默认 DINOv2-Small 的 patch size 为 14：

```text
输入                         (B, 3, 168, 224)
四层 DINO patch feature      4 x (B, 384, 12, 16)
通道投影                     4 x (B, 128, 12, 16)
拼接                         (B, 512, 12, 16)
融合                         (B, 128, 12, 16)
第一次上采样                 (B, 128, 24, 32)
第二次上采样                 (B, 64, 48, 64)
恢复标签尺寸                 (B, 64, 168, 224)
Heatmap head                 (B, 8, 168, 224)
```

四个中间层同时提供局部位置和全局结构信息。相比只解码 DINO 最后一层，它更适合精确角点定位。

## 坐标监督

Heatmap 经过 spatial soft-argmax：

```text
softmax(temperature * heatmap)
-> 每个像素的空间概率
-> 概率加权 x/y 坐标
-> (B, 8, 2)
```

训练使用可微坐标；推理使用最大峰的局部加权质心。坐标损失先除以图像宽高归一化，避免像素尺度压过 Heatmap 损失。

## Checkpoint

checkpoint 只保存：

- 可训练解码器权重（DINOv2 预训练权重由 Torch Hub 提供，不重复保存）；
- 最佳验证角点误差。

训练和推理固定构造同一个 `CornerHeatmapNet`，不提供其他架构分支。

## 当前限制

- 默认 backbone 冻结。数据量增加后可以尝试用更低学习率微调最后两个 DINO block。
- 真实测试依赖尚未训练的相机 YOLO 检测器权重。
